Section A

Buyer Operations

The full buyer journey — from first contact to post-closing. Click each phase to expand.

1. Buyer Consultation & Intake ⌄
  1. TCAgent Lead comes in via Lofty (TC follows up) or direct to agent (agent adds to Lofty + Trello "New Leads," tags Coordinator to schedule consult)
  2. TC Send Buyer Questionnaire Guide, move card to "Consult Scheduled," confirm Intake Form is done (send reminder day-of if not)
  3. Agent Send Buyer Presentation — TC adds consult to agent's calendar + invites client
  4. Agent Hold Initial Consultation — Google Meet, screen share on, 30 minutes
  5. Agent Comment on Trello card with next steps, tag TC (e.g. "send Buyer Agency for signing")
  6. TC Complete requested follow-up (send Buyer Agency, etc.) — for an agent's first 3 transactions, agent sends all docs themselves
  7. TC Once BA is signed, send the Thank You email
  8. TC Send the "All About You" form
  9. TCAgent Confirm buyer is pre-approved or pre-qualified with a lender
If This → Do This
IF: Buyer wants to see homes before being pre-approved/pre-qualified → DO: Do not schedule showings until a pre-approval or pre-qualification letter is on file. If they push back, loop in the agent.
2. Property Search & Showings ⌄
  1. TC Add contact to Lofty — Agent sets up a saved search on buyer criteria
  2. TCAgent Save buyer as a contact in MLS
  3. TCAgent Schedule showings and open houses (see ShowingTime steps)
  4. TC For each showing: send property details + documents; calendar invite once confirmed
  5. TC For multi-stop tours: check the smart route, send itinerary + documents + calendar invite
If This → Do This
IF: Buyer's search criteria change mid-search → DO: Update the Lofty/MLS saved search the same day and confirm the new criteria with the buyer.
3. Offer Preparation ⌄
  1. Agent Set up the offer in ZipForms with all needed documents — Residential Offer to Purchase, Addendum RA, Add S, RECR, Real Affiliated Business Arrangement, Consumer Choice & Referral Fee Disclosure
If This → Do This
IF: Buyer wants to write on a property they haven't seen in person → DO: Escalate to Cailyn.
4. Under Contract (Offer Acceptance) ⌄
  1. TC Send separate congrats emails to buyer + listing agent, with the completed AO Packet attached
  2. TC Confirm with lender, send "Accepted Offer & Key Transaction Details" email (commission, responsibility, admin fee)
  3. TC Remind buyer Earnest Money is due 1 day after AO — include amount + wiring instructions, confirm once sent
  4. TC Add the transaction to Rezen, complete setup per the Rezen SOP
  5. TC Send buyer the List of Inspectors for reference
  6. TC Once EM received — confirm receipt, send receipt to LA/Lender/Title, upload to Rezen
  7. TC Send Title Company info to Lender; update Title/closer info in Rezen
  8. TC Coordinate with Lender on loan processing + appraisal scheduling; confirm contingency deadlines; update Rezen
  9. TC Review HOA/condo/subdivision docs if applicable; confirm buyer receives + knows review deadlines; track in Rezen
  10. TC Order BizBox using intake info — verify mailing address first
  11. TC Add all contingency/transaction deadlines to the calendar (inspection, financing, appraisal, well/septic, title); invite client; keep updated
If This → Do This
IF: Earnest Money is not received by the deadline → DO: Follow up with the buyer 2 days before it's due. If still no action by the deadline, notify the agent and Cailyn immediately — buyer may be at risk of default.
IF: An offer is being written but Buyer Agency was never signed → DO: Require a signed BA or Disclosure to Customer before writing or submitting any offer.
5. Inspection & Due Diligence ⌄
  1. TC Confirm buyer has scheduled/completed required inspections; remind of deadline if not
  2. TC Schedule inspection in Showing Platform once buyer confirms date/time
  3. TC Add inspection to team calendar, invite buyer, include full appointment details
  4. TC Send inspection reminder email 1 day before — property, date/time, inspector contact, what to expect
  5. TC When report is received, email it to buyer + a scheduling link to review with Agent — do not interpret findings before Agent reviews
  6. TC Upload the inspection report to Rezen
  7. TC Send all inspection reports to the Listing Agent
  8. TC For amendments/inspection addenda — Agent prepares, buyer signs, send to LA for seller signature, distribute fully executed copy to Lender/Title, upload to Rezen
  9. Agent Review all reports with the buyer (foundation, radon, septic, well, pest, roof, etc.)
  10. TC Confirm buyer's preferred closing time + final walkthrough; coordinate with Title; update calendar + Rezen
  11. TC Confirm utility transfer details with Listing Agent; relay to buyer
If This → Do This
IF: Inspection reveals a major or structural issue → DO: Escalate to the agent and Cailyn.
IF: A contingency deadline is at risk of being missed → DO: Notify the agent and Cailyn at least 48 hours before, so an extension addendum can be prepared if needed.
6. Financing & Appraisal ⌄
  1. TC Monitor loan approval with lender; follow up 2 days before financing contingency is due; notify Agent of delays; update Rezen
  2. TC When Loan Commitment is received — review for required signatures, send to buyer if needed, follow up to completion
  3. TC Upload the Loan Commitment to Rezen
If This → Do This
IF: Financing contingency deadline is approaching with no Loan Commitment → DO: Escalate to the agent and lender immediately — buyer may need a financing extension addendum.
7. Finalizing the Deal ⌄
  1. Agent Review the closing disclosure + final loan documents for accuracy
  2. TC Send closing reminder/confirmation email to Listing Agent, Title, and Lender
  3. Team Lead Verify commission has been reviewed and approved
  4. TC Download the CDA, send to Title for review — note Real Broker prefers wire over check
  5. TC Send buyer a final walkthrough reminder + congrats email with confirmed dates
  6. TC Add confirmed walkthrough + closing dates to the agent's and client's calendars
  7. TC When the final ALTA is received, send it to the buyer for final review
  8. TC Upload the ALTA to Rezen
If This → Do This
IF: The CDA has not been approved by Cailyn → DO: Do not send it to Title until Cailyn has approved it.
8. Closing ⌄
  1. TC Send the final congratulatory message to the buyer after closing is confirmed
  2. TC Add "past client – buyer" and "VIP" tags in Lofty
  3. TC Remove the client's saved search from Lofty and Paragon
  4. TC Set up a quarterly market snapshot using the new address/ZIP
  5. TC Certify the closing in Rezen; upload final ALTA, closing statement, commission wire confirmation, and all closing docs
If This → Do This
IF: Closing date changes within 48 hours of closing → DO: Notify buyer, listing agent, title, and lender immediately; update all calendar invites and the transaction file.
9. Post-Closing ⌄
  1. TC Complete all post-closing follow-ups — utility transfers, final docs/resources, outstanding items
  2. TC Send a thank-you note; request a review/testimonial with link
  3. Agent Update client records in Lofty (contact info, history, tags); maintain ongoing nurture touchpoints
  4. TC Coordinate the closing gift with vendor — name, address, closing date, occupancy details
If This → Do This
IF: Buyer has a post-closing issue (repair, warranty claim, etc.) → DO: Direct them to the appropriate resource (home warranty provider, inspector, etc.) and loop in the agent.
Section B

Buyer Showing

Everything you need before, during, and after a showing.

Pre-Showing Pipeline ⌄

Stage 1 — Buyer Wishlist

Add when: they inquire + want to buy in 0–18 months (or "someday" with detail) + you have name/contact/basic preferences + haven't consulted or signed BA yet.

  1. Add contact info + notes to CRM
  2. Copy template card, add notes
  3. Tag lead source in Trello
  4. Send "nice to meet you" message
  5. Offer consultation times
If This → Do This
IF: They agree to a consult time → DO: Move to Consultation once it's booked and confirmed.

Stage 2 — Consultation

  1. Send confirmation text/email (time, date, how to join)
  2. Send pre-consult forms / intake questionnaire
  3. Prep notes: price range, areas, timeline, financing status
  4. Conduct consultation — goals, agency, pre-approval/budget, next steps, search/showing process
  5. Add consult notes to buyer's Lofty profile
If This → Do This
IF: They're not ready to sign BA yet → DO: Keep in Pending if a follow-up date is set, or move to Leads to Follow Up if timing is long-term/uncertain.

Stage 3 — BA Signed

  1. Save signed BA in transaction folder/CRM
  2. Update Trello card with BA start/end dates
  3. Confirm cash vs. financed, pre-approved or needs lender intro
  4. Introduce lender options if needed
If This → Do This
IF: BA is signed but buyer is waiting on something big (job change, house sale) → DO: Keep in BA Signed, label "On Hold" with a revisit date.

Stage 4 — Property Search

  1. Set up/refine saved search & alerts
  2. Confirm "Top 3" neighborhoods/areas
  3. Start sending properties + gathering feedback
  4. Schedule showings based on interest
  5. Track homes viewed, favorites, feedback
If This → Do This
IF: Buyer pauses their search → DO: Move to On Hold.
IF: They go silent or choose another agent → DO: Move to Lost/Not Active.
IF: An offer is accepted and fully executed → DO: Move to Buyer Under Contract.
Scheduling ⌄
  1. Coordinator Buyer contacts agent or coordinator to request a showing
  2. Agent If buyer contacts agent first — forward the request to coordinator via Slack within 2 hours
  3. Coordinator Confirm availability with listing agent(s)
  4. Coordinator Schedule confirmed showing(s) in the MLS showing system
  5. Coordinator Send confirmation email within 12 hours — date/time/address, what to expect, agent's cell, all documentation attached
  6. Coordinator Notify agent via Slack that the showing is confirmed and documents are sent
Document Prep ⌄

Coordinator sends buyer digitally (with the confirmation email)

  • MLS listing sheet — customer version
  • Real Estate Condition Report (RECR)
  • Any additional seller disclosures

Agent prints/preps a physical packet per property

  • MLS sheet, customer version — stapled to RECR + forms — this is the buyer's copy
  • MLS sheet, agent version — agent's own notes, never given to buyer
  • RECR
  • Additional disclosures (HOA rules, condo docs, amendments)
  • One labeled folder per property

For equine, rural, or acreage properties also pull

  • Well and septic records or disclosure
  • Outbuilding, barn, or arena specs
  • Acreage, pasture, and fencing documentation
  • Zoning, agricultural use, or land use restriction records
  • Easements or survey if available

Agent assembles all property folders into one tour packet, organized in showing order.

Pre-Showing Review ⌄

Owner: Agent — do this before departing for the showing, not in the parking lot.

  1. Read the full RECR for each property — flag anything material (water intrusion, structural, mechanical, known defects)
  2. Review all additional disclosures/forms — permit issues, boundary disputes, HOA restrictions, well/septic age
  3. Make notes on your agent MLS sheet — never write on the buyer's copy
  4. Identify 2–3 specific discussion points per property, drawn from the documents
  5. For equine/rural properties, also review: stall count, arena type/footing, fencing disclosures; well/septic age + service history; zoning/use restrictions; outbuilding condition/permits
The Showing ⌄

Arrival

  1. Arrive at the first property no less than 5 minutes early
  2. Do not enter until the exact scheduled time — legal/professional standard
  3. Tell buyers up front: "We legally cannot be on the property until our exact showing time — meet me out front."
  4. If early, wait outside until showing time
  5. On entry, before buyers arrive: lights on everywhere, property presentable, quick walkthrough for surprises, unlock interior areas

During the Walkthrough

  1. Walk buyers in through the front door whenever possible
  2. Set expectations at the start: "You're welcome to open cabinets, closets, and doors — just don't touch personal belongings."
  3. Address shoes at entry — agent models removing shoes/booties first
  4. Lead the buyer through intentionally — don't just follow them
  5. Use the "change vs. cannot change" framework: can change (flooring, paint, fixtures, landscaping); cannot change (location, lot size, layout, ceiling height, proximity)
  6. Never diagnose defects — flag for inspection instead
  7. Make notes on your agent MLS sheet during the tour
Script — Memorize This
NEVER SAY: "That's mold." / "The foundation is cracked." / "That's a bad roof." → ALWAYS SAY: "That's worth having an inspector evaluate." / "I'd recommend we get eyes on that during inspection."
Full Property Coverage — Non-Negotiable
BASEMENT: Always go down → CHECK: mechanicals, water intrusion signs, ceiling height, structural walls.
GARAGE: Walk the full garage → CHECK: size, door condition, floor, storage/utility concerns.
EXTERIOR: Walk it before leaving → CHECK: roof, siding, grading toward/away from house, gutters/downspouts, deck/patio.
EQUINE/RURAL: Additional exterior pass → CHECK: fencing, pasture quality/drainage, barn/outbuilding exteriors, arena footing/drainage, driveway trailer access.

Departure Protocol

  1. Final walkthrough — lights off (unless instructed otherwise), every door locked (verify yourself), lockbox secured, property as found
  2. Ask for immediate buyer feedback: "1–10, where did that land for you?" / "What did you love? Concerns?" / "Stay on the list or move on?"
  3. Capture responses in notes and Lofty after the tour
